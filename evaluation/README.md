# evaluation

## Purpose

The scientific and engineering measurement layer: benchmarks, metrics, harnesses, regression testing, language-aware evaluation, and reports.

## Boundary

Must cover model quality, language quality, speech quality, regression, latency, and multilingual performance. Does not contain the models being evaluated (see models/) or training logic (see training/).

## Status

This is an architectural scaffold. This directory currently contains no
implementation. Its existence defines an intended ownership boundary within
the Sauti Labs master architecture; it does not imply that this capability
has been built. See the AI CTO Constitution and `docs/Enhancements.md` for
how real work is tracked as it actually happens.
