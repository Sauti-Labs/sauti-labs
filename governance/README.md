# governance

## Purpose

Technology governance: licensing, data governance, provenance, security, privacy, and policies. Especially important given Sauti Labs works with human speech, datasets, language communities, and third-party licensed resources.

## Boundary

This is governance and policy - not the systems being governed. governance/privacy/ specifically covers privacy, consent, retention, and access-control rules; it is not the speaker registry itself, which will migrate into data/ in a later, separately authorized step.

## Status

This is an architectural scaffold. This directory currently contains no
implementation. Its existence defines an intended ownership boundary within
the Sauti Labs master architecture; it does not imply that this capability
has been built. See the AI CTO Constitution and `docs/Enhancements.md` for
how real work is tracked as it actually happens.
