# governance / privacy

## Purpose

Privacy, consent, retention, and access-control governance rules, per ADR-0002's privacy-by-architecture principle.

## Boundary

This is governance and policy, not the speaker registry itself - the speaker-registry framework (actual pseudonymous speaker records and consent data) will migrate into data/ in a later, separately authorized step.

## Status

This is an architectural scaffold. This directory currently contains no
implementation. Its existence defines an intended ownership boundary within
the Sauti Labs master architecture; it does not imply that this capability
has been built. See the AI CTO Constitution and `docs/Enhancements.md` for
how real work is tracked as it actually happens.
