# research

## Purpose

The experimental layer: experiments, hypotheses, reproductions, prototypes, ablations, notebooks, and publications. Scientific investigation happens here.

## Boundary

Research prototypes may be unstable. Production systems should not depend directly on arbitrary notebooks - there must be a clear path from research to validated implementation to model to evaluation to production.

## Status

This is an architectural scaffold. This directory currently contains no
implementation. Its existence defines an intended ownership boundary within
the Sauti Labs master architecture; it does not imply that this capability
has been built. See the AI CTO Constitution and `docs/Enhancements.md` for
how real work is tracked as it actually happens.
